# 수익화 체크리스트: 구글 애드센스 + 쿠팡 파트너스

티스토리 블로그에 애드센스와 쿠팡 파트너스를 함께 쓰는 것과 같은 방식으로 웹앱(`web/`)에 적용합니다.
광고·제휴 관련 작업을 할 때는 **이 문서를 먼저 읽고 순서대로 진행**하세요.

> 정책은 자주 바뀝니다. 신청이나 적용 직전에 아래 '공식 확인처'에서 최신 내용을 다시 확인하고, 바뀐 점이 있으면 이 문서부터 고치세요.
> 마지막 정리: 2026-10-06 (공개 자료와 블로그 안내 기준. 쿠팡 파트너스 운영정책 원문은 아직 직접 확인하지 못함)

## 0. 공통 준비 (둘 다 신청 전에)

- [ ] 실제 도메인 연결, HTTPS 적용 → `web/site.config.js`의 `siteUrl` 변경
- [ ] `operator.name`, `operator.email` 입력 (소개·개인정보처리방침·이용약관에 표시됨)
- [ ] 개인정보처리방침의 `[TODO]` 채우기: 호스팅 업체명과 접속 기록 보관 기간
- [ ] 소개(/about/), 광고·제휴 안내(/disclosure/), 개인정보처리방침(/privacy/), 이용약관(/terms/) 공개 확인
- [ ] 직접 확인하고 편집한 일정 글을 충분히 쌓기. AI로 찍어낸 비슷한 페이지만 많으면 애드센스 심사에서 '가치가 별로 없는 콘텐츠'로 거절될 수 있음
- [ ] 주최 측 포스터·배치도 이미지는 허락 없이 싣지 않기 (출처 링크로 대신)
- [ ] 개인정보처리방침과 이용약관은 배포 전에 법률 검토 권장

## 1. 쿠팡 파트너스

공식: https://partners.coupang.com (가이드·운영정책은 로그인 후 확인)

### 가입과 사이트 등록
- [ ] partners.coupang.com에서 회원가입 (개인 또는 사업자)
- [ ] 활동 채널에 **이 웹사이트 URL** 등록 (티스토리 블로그 주소를 등록하는 것과 같은 단계)
- [ ] 사이트에 실제로 제휴 링크를 단 페이지를 만든 뒤, 활동이 보이는 **스크린샷을 채널 정보에 업로드**
- [ ] 최종 승인: 누적 판매금액이 **15만 원 이상**이 되면 채널 검토가 진행됨. 최종 승인 전에는 수익이 정산되지 않음
- [ ] 정산(참고): 월 수익 1만 원 이상일 때 지급, 보통 다다음 달 15일. 지급 정보(신분증·계좌) 등록 필요

### 대가성 문구 (가장 중요)
- 문구: **"이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."**
- 위치: 공정위 추천·보증 심사지침에 따라 **게시물 제목 또는 첫 부분**에, 소비자가 쉽게 알아볼 수 있게. 본문 중간이나 맨 아래에만 두면 쿠팡이 '고지 미흡'으로 보고 수익을 회수한 사례가 있음
- 코드 반영 상태:
  - [x] 제휴 링크가 있는 일정 페이지는 `<main>` 맨 위(제목보다 앞)에 문구를 자동 표시 (`web/src/templates.js` → `layout`)
  - [x] 문구가 비거나 "쿠팡 파트너스"·"수수료"가 빠지면 빌드 실패 (`validateMonetization`)
  - [x] 제휴 링크는 `rel="sponsored nofollow noopener"`, 링크 옆에 '쿠팡' 표시
  - [x] 쿠팡 도메인(`link.coupang.com`, `coupa.ng`)이 아닌 URL은 제휴 링크로 쓰지 않음
  - [x] /disclosure/ 페이지에 문구와 설명 표시
  - [ ] 쿠팡 배너·다이내믹 배너(iframe/script)를 쓰기로 하면: 배너가 들어간 페이지에도 문구가 맨 위에 나오도록 `planHasAffiliate` 조건을 넓히고 테스트 추가

### 하지 말 것 (운영정책에서 흔히 금지하는 행위. 원문으로 재확인 필요)
- 쿠팡을 사칭하거나 쿠팡 공식 페이지처럼 보이게 만들기
- "클릭해 주세요" 같은 클릭 유도, 본인 구매나 지인 구매 유도
- 링크 숨기기, 자동 리다이렉트, 팝업으로 강제 이동, 보이지 않는 iframe으로 쿠키 심기
- 사실과 다른 리뷰나 과장 표현

### 켜는 방법
1. `web/data/plans/*.json`의 준비물에 링크 추가: `"prep": [{ "name": "돗자리", "coupangUrl": "https://link.coupang.com/a/..." }]`
   날짜별 상품은 `days[].products`에 같은 형식으로 넣어도 됨
2. `web/site.config.js` → `monetization.coupang.enabled: true`
3. `npm test && npm run build` 후 일정 페이지 맨 위에 문구가 보이는지 직접 확인

## 2. 구글 애드센스

공식: https://support.google.com/adsense/answer/12169212 (사이트 추가), https://support.google.com/adsense/answer/7584263 (사이트 연결)

### 신청과 승인
- [ ] 애드센스 가입 → 사이트 추가에 도메인 입력
- [ ] 사이트 소유 확인: 애드센스 코드 스니펫, ads.txt, 메타 태그 중 하나
- [ ] `site.config.js`에 `adsense.client`('ca-pub-' + 16자리) 입력 후 `enabled: true` → 빌드하면
  - 모든 페이지 `<head>`에 애드센스 스크립트가 들어감
  - 사이트 루트에 `ads.txt`가 생성됨: `google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0`
- [ ] 심사 대기: 보통 며칠, 길면 2~4주. 거절되면 사유를 이 문서에 기록
- [ ] 승인 후 애드센스에서 광고 단위를 만들고 `slots.home`, `slots.planTop`, `slots.planBottom`에 data-ad-slot 값 입력. 비워 둔 자리는 출력되지 않음

### 개인정보와 동의
- [x] 애드센스를 켜면 개인정보처리방침에 구글 광고 쿠키 안내와 맞춤 광고 해제 링크가 자동으로 들어감 (`web/src/pages.js`)
- [ ] 켤 때 `privacyEffectiveDate`를 그날로 바꾸기
- [ ] 애드센스 > 개인정보 보호 및 메시지에서 동의 메시지 설정. 유럽경제지역(EEA)·영국·스위스 방문자에게 광고하려면 구글 인증 CMP(IAB TCF 연동)가 필수 (2024년 1월부터, TCF v2.3 기준)
- [ ] 동의 메시지에 개인정보처리방침 URL 연결

### 배치 원칙
- 광고에는 항상 "광고" 표시 (`.ad-label`, 구현됨)
- 광고를 일정 정보나 버튼처럼 보이게 두지 않기. 탭·내비게이션·준비물 체크박스 바로 옆에 두지 않기
- 쿠팡 제휴 링크와 애드센스 광고를 붙여 놓아 서로 헷갈리게 하지 않기
- 클릭 유도 문구 금지, 본인 클릭 금지

## 3. 모바일 앱으로 감쌀 때 (나중에)

- 웹뷰 앱(Capacitor, TWA)에 애드센스 웹 광고를 그대로 띄우는 것은 정책상 제한될 수 있음. 앱에서는 AdMob을 쓰고, 웹뷰 광고가 필요하면 Google Mobile Ads SDK의 WebView API 요건을 확인
- 쿠팡 파트너스는 앱도 활동 채널로 등록해야 하는지 확인하고, 앱 화면에도 대가성 문구가 맨 위에 보이는지 확인
- 앱 스토어 개인정보 항목(데이터 안전 섹션 등)에 광고 식별자 사용 여부 반영
